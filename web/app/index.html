The hard part of this project. “iPhone 15 128GB Blue” and “iPhone 15 256GB Blue” are about 97% similar as text but are different products. Embeddings capture topic, not specification — so hard attributes are enforced as constraints, never learned.

Stage 1 — blocking: attributes are extracted from each title with rules. Listings whose brand · storage · colour disagree land in different blocks and can never merge. Stage 2 — semantic clustering: inside each block, titles are embedded and clustered by cosine similarity. Model number and generation act as extra must-not-link constraints.
